By the end of this page, Slowave will be running and connected to your coding agent.

**You need:** Python 3.11 or newer, and one supported coding agent. Slowave runs on macOS, Linux and Windows.

<Steps>
  <Step title="Install Slowave">
    ```bash
    pipx install slowave
    ```
  </Step>
  <Step title="Preview the changes">
    This shows what setup will change. It does not change anything.

    ```bash
    slowave setup --dry-run
    ```
  </Step>
  <Step title="Run setup">
    Setup connects every supported agent it finds and starts Slowave in the background.

    ```bash
    slowave setup
    ```

    <Check>
      Run `slowave doctor` to confirm everything is healthy.
    </Check>
  </Step>
  <Step title="Open the dashboard">
    ```bash
    slowave dashboard
    ```

    Your browser opens a local page. It's empty for now.
  </Step>
  <Step title="Give your agent a rule">
    Open your coding agent and say something worth keeping. For example: "In this project, always write dates in UTC."

    Then start a new session and ask for something that involves dates. Your agent should follow the rule without being told again.
  </Step>
</Steps>

<Note>
  Cursor and Claude Desktop need one manual paste after setup. See [Integrations](/integrations/overview).
</Note>

<AccordionGroup>
  <Accordion title="The first run feels slow">
    On first use, Slowave downloads a small search model of about 45 MB. It is then cached and works offline.
  </Accordion>
  <Accordion title="My agent doesn't seem to remember">
    Run `slowave doctor`, then restart your agent. See [Troubleshooting](/troubleshooting).
  </Accordion>
  <Accordion title="I want to undo setup">
    Run `slowave uninstall`. It removes the connections and keeps your memory. See [Uninstall](/uninstall).
  </Accordion>
</AccordionGroup>
