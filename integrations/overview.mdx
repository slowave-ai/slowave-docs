Slowave connects to the coding agents you already use. Every agent you connect reads and writes the same local memory.

One command sets up every supported agent it finds:

```bash
pipx install slowave
slowave setup --dry-run
slowave setup
```

To set up a single agent, add `--client` with its name. Choose an agent below for its guide.

| Windsurf | macOS, Linux, Windows | Automatic |
| Cline | macOS, Linux, Windows | Automatic |
| Claude Desktop | macOS, Linux, Windows | One manual paste |

Automatic means setup writes both the connection and the instructions. Cursor and Claude Desktop need you to paste the instructions that setup prints.

## How all agents share one memory

Slowave runs one small background service on your machine. Each agent connects to it through MCP, so they all use the same memory.

Something you teach Claude Code can help Codex or Cursor later. Memory stays on your machine, and you can browse it with `slowave dashboard`.
