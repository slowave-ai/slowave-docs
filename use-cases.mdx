<CardGroup cols={2}>
  <Card title="Keep your conventions" icon="book-check">
    Say how you name things or structure tests once. Every later session follows it.
  </Card>
  <Card title="Switch agents freely" icon="arrow-left-right">
    Start a feature in Claude Code and finish it in Cursor. Both read the same memory.
  </Card>
  <Card title="Stop re-debating decisions" icon="messages-square">
    Record why you rejected an option. Your agent won't suggest it again next week.
  </Card>
  <Card title="Handle changing rules" icon="refresh-cw">
    Update a rule once. The old version is retired, not left to contradict the new one.
  </Card>
  <Card title="Reuse what worked" icon="list-checks" href="/procedures">
    A good way of adding an endpoint, a migration or a test becomes a procedure your agent can reuse.
  </Card>
  <Card title="Pick up after a break" icon="calendar-clock">
    Return to a project after weeks. Your agent starts with the decisions you made, not a blank page.
  </Card>
</CardGroup>
